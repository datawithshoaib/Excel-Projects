# Excel Projects

Dashboard and data analysis projects built in Microsoft Excel.

## Projects

### [Call Centre Dashboard](Call%20Centre%20Dashboard/)

An interactive dashboard that tracks call centre performance: total calls and call duration, average satisfaction rating, 5-star calls, and how purchase amounts relate to calls. A `Pivots` sheet with slicers lets you filter by representative, date and customer attributes.

![Call Centre Dashboard](Call%20Centre%20Dashboard/call_centre_dashboard.png)

**Skills:** data cleaning, pivot tables, slicers, KPI design, dashboard layout.

## Open a project

Download the `.xlsx` file from the project folder and open it in Excel (2016 or later). Each project folder has its own README with the full walkthrough.
